# TravelMatch

A quiz-based travel recommender: answer a few questions about your travel
preferences and get matched destinations with a suggested time to go, a
budget estimate, and a recommended stay length.

**Live:** https://travelmatch-frontend.onrender.com

## Structure

- `frontend/` — React (Vite) quiz UI.
- `backend/` — PHP API (scoring, RAG-generated descriptions, auth, search).
- `mcp-server/` — MCP server exposing the matching engine as a tool.
- `automation/` — n8n workflows for result/verification/reset emails.
- `tests/` — PHPUnit tests for the backend.

## Run it locally

**1. Database** — create a Postgres database, then load
`backend/database/schema.sql` and everything in
`backend/database/migrations/` (in order) against it.

**2. Backend** — create `backend/.env`:

```
DB_HOST=localhost
DB_PORT=5432
DB_NAME=travelmatch
DB_USER=travelmatch
DB_PASSWORD=...
GEMINI_API_KEY=...   # optional — https://aistudio.google.com/apikey
```

Then:

```
php -S localhost:8000 -t backend backend/index.php
```

**3. Frontend**

```
cd frontend
npm install
npm run dev
```

Calls the API at `http://localhost:8000/api` by default (override with
`VITE_API_URL` in `frontend/.env`).

## Deployment

Everything runs on Render — backend (Docker web service), database (managed
Postgres), frontend (static site) — provisioned in one go from `render.yaml`
via **New → Blueprint** in the Render dashboard. See comments in
`render.yaml` and `Dockerfile` for the details.

## API

`register`, `login`, `logout`, `me`, `match`, `history`, `destinations`,
`search`, `favorites`, `profile`, `change-password`, `forgot-password`,
`reset-password`, `notify`, `health` — all under `/api/*.php`. See
`backend/api/` for request/response shapes.

## AI descriptions & semantic search

Result descriptions are generated by a RAG pipeline (`backend/src/Services/Rag.php`) grounded in curated facts + a live Wikipedia extract, with a
deterministic fallback and a post-generation groundedness check — never an
unverified LLM response. The Explore page's free-text search embeds the
destination catalog with Gemini and ranks by cosine similarity
(`backend/src/Services/Embeddings.php`). Details are in those files' comments.
